# AI자율주행시스템공학과 전공체험 안내

신입생 전공탐색 행사에서 QR 코드로 열 수 있도록 만든 정적 웹페이지입니다.

## 포함 내용
- AI자율주행시스템공학과 소개
- 교과목 흐름
- 자율주행 시스템 파이프라인
- F1TENTH 자율주행 레이싱
- LIMO 자율이동로봇
- AMET 대회 프로젝트
- VLM 기반 Vision-Language Navigation
- 졸업 후 진로
- 미니 자율주행 부스 체험 안내

## GitHub Pages
Repository Settings → Pages → Build and deployment에서 `Deploy from a branch`, `main`, `/ (root)`를 선택하면 공개됩니다.

예상 공개 주소:
`https://mudokim.github.io/ai-autonomous-driving-major/`

## 미디어 추가
F1TENTH, LIMO, AMET, VLM의 실제 사진과 영상은 이후 `assets/` 폴더에 추가하고 `index.html`의 각 placeholder를 교체하면 됩니다.
