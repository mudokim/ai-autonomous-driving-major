> **AI가 보고, 판단하고, 움직이게 만드는 전공**  
> AI × Robotics × Autonomous Driving

## 1. 학과 소개

AI자율주행시스템공학과는 인공지능, 컴퓨터비전, 로봇, 센서, 제어, 자율주행 소프트웨어를 연결해 **실제로 움직이는 지능형 시스템**을 만드는 전공입니다.

쉽게 말하면 다음 세 단계가 핵심입니다.

- **보고**: Camera, LiDAR, IMU 등 센서로 주변 환경을 인식합니다.
- **판단하고**: 현재 위치를 추정하고, 어디로 갈지 계획하고, 상황에 맞는 의사결정을 합니다.
- **움직인다**: 조향, 속도, 모터를 제어해 실제 차량이나 로봇이 움직이게 합니다.

즉, 단순히 AI 모델만 만드는 것이 아니라 **AI를 실제 로봇과 차량에 연결하는 시스템 공학 전공**입니다.

## 5. 자율주행 시스템은 어떻게 동작할까?

전체 흐름은 다음과 같습니다.

**Sensor → Perception → Localization → Planning → Control**

- **Sensor**: Camera · LiDAR · IMU
- **Perception**: Computer Vision · Deep Learning
- **Localization**: Sensor Fusion · State Estimation
- **Planning**: Path Planning · AI Planning
- **Control**: Steering · Speed · Motion

각 과목은 따로 떨어져 있는 것이 아니라 실제 자율주행 시스템에서 하나로 연결됩니다.

### VLM Navigation / Vision-Language Model

Vision-Language Model을 자율주행·로봇 내비게이션 문제에 적용해 **이미지와 자연어 지시를 함께 이해하고 주행 행동을 결정하는 AI**를 학습한 프로젝트입니다.

- Base model: **Qwen/Qwen3-VL-2B-Instruct**
- 입력: Navigation instruction + 연속 RGB 이미지 2장
- 이미지 크기: 256×256
- Vision encoder: Qwen3 ViT 고정
- Fine-tuning: Language model의 `q_proj`, `v_proj`에 LoRA 적용
- 출력: 4가지 주행 action string 중 하나
- LoRA rank 16
- LoRA alpha 32
- LoRA dropout 0.05
- 10 epochs
- AdamW
- cosine warmup

구조는 다음과 같습니다.

**Navigation Instruction + RGB Frame(t-1) + RGB Frame(t) → Qwen3-VL → Driving Action**

기존 자율주행이 센서값을 여러 모듈로 나누어 처리하는 구조라면, VLM은 이미지와 언어를 함께 이해해 더 높은 수준의 상황 판단과 행동 결정을 시도하는 접근입니다.

**관련 키워드**  
`VLM` `Qwen3-VL` `LoRA` `Vision-Language` `Navigation` `Multimodal AI`

> 🎥 **영상 자리 — VLM 입력/출력 데모 영상 삽입 예정**

## 8. 전공 선택 시 고려하면 좋은 점

이 전공은 다음과 같은 학생에게 잘 맞습니다.

- AI뿐 아니라 실제 로봇과 차량이 움직이는 것을 좋아하는 학생
- Python, C++, ROS2 같은 프로그래밍을 배우고 싶은 학생
- 수학, 물리, 제어, 센서에 거부감이 없는 학생
- 직접 실험하고 디버깅하면서 문제를 해결하는 것을 좋아하는 학생
- 자율주행차, 로봇, 드론, AMR, 스마트팩토리 분야에 관심이 있는 학생

단순 코딩만 하는 전공이라기보다 **소프트웨어 + 센서 + 제어 + 하드웨어를 연결하는 전공**이라고 보는 것이 정확합니다.

## 11. 부스 체험 — Mini Autonomous Driving Challenge

### Mission

**작은 로봇이 스스로 FINISH까지 갈 수 있을까?**

라인트레이싱 또는 장애물 감지 미니 로봇을 이용해 간단한 자율주행 체험을 진행합니다.

체험 흐름은 다음과 같습니다.

1. 센서가 라인 또는 장애물을 감지합니다.
2. 로봇이 현재 상황을 판단합니다.
3. 모터를 제어해 경로를 따라갑니다.
4. 실제 F1TENTH 영상과 비교하면서 기술이 어떻게 확장되는지 설명합니다.

### 예산 예시

| 준비물 | 용도 | 예상 예산 |
|---|---|---:|
| 미니 로봇카 2대 | 라인 추종 / 장애물 감지 | 60,000~100,000원 |
| 라인 테이프 + 미니 라바콘 | 테이블 위 코스 제작 | 15,000~25,000원 |
| A3 폼보드 / QR 출력 | 학과 및 프로젝트 안내 | 20,000~30,000원 |
| 소형 기념품 | 미션 성공 참가자 제공 | 20,000~30,000원 |

작은 로봇에서 시작하지만, 학과에서 배우는 컴퓨터비전·LiDAR·센서융합·경로계획·제어 기술을 더하면 실제 자율주행 시스템으로 확장됩니다.
