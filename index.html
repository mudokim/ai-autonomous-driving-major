VLM Navigation

Vision-Language Model을 로봇·자율주행 내비게이션 문제에 적용해 이미지와 자연어 지시를 함께 이해하고 주행 행동을 결정하도록 학습한 프로젝트입니다.

  • Base model: Qwen/Qwen3-VL-2B-Instruct
  • 입력: Navigation instruction + 연속 RGB 이미지 2장
  • 이미지 크기: 256×256
  • Vision encoder(Qwen3 ViT)는 고정
  • Language model의 q_proj / v_proj에 LoRA 적용
  • 4가지 주행 action string 중 하나를 예측
  • LoRA rank 16 / alpha 32 / dropout 0.05
  • 10 epochs · AdamW · cosine warmup
VLMQwen3-VLLoRAVision-Language

입력 이미지 + 자연어 명령 + 예측 Action 시각화 위치
VLM을 쉽게 이해하면
전통적인 자율주행은 센서 데이터에서 인식·위치추정·경로계획을 단계별로 연결합니다. VLM은 여기에 언어 이해를 더해 “앞의 장애물을 피해 오른쪽으로 이동해” 같은 자연어 지시와 이미지를 함께 보고 높은 수준의 행동을 결정하는 방향을 실험합니다.

행사 운영 안내

처음 안내된 행사 운영 내용을 AI자율주행시스템공학과 부스에 맞춰 정리했습니다.

전공안내 운영

전공별 교육과정과 특성을 소개하고, 전공 관련 비교과 프로그램, 졸업 후 진로 및 취업 분야, 전공 선택 시 고려사항, 재학생의 실제 학습·대학생활 경험을 공유합니다. 이 페이지의 전공안내·교과과정·프로젝트·진로 섹션이 해당 내용을 담당합니다.

전공 체험 콘텐츠 운영

전공별 미니 체험, 실험·실습 콘텐츠, 퀴즈 및 미션형 프로그램을 운영합니다. AI자율주행시스템공학과는 미니 로봇 자율주행 챌린지 + 센서/AI 퀴즈 + 실제 F1TENTH/LIMO 영상 연결 구성이 적합합니다.

연구성과 전시

캡스톤디자인 우수작품, 학부연구생 연구성과, 전공별 대표 프로젝트 및 연구활동을 소개합니다. F1TENTH·LIMO·AMET·VLM 프로젝트 설명을 대표 사례로 활용할 수 있습니다.

전공별 운영예산

전공별 배정금액은 200,000원이며 행사 운영에 필요한 재료비와 체험 물품은 전공별로 준비합니다. 물품 구입이 필요한 경우 구매플랫폼에서 장바구니에 담은 뒤 새내기지원팀(학생회관 2층 200호) 방문 시 법인카드 결제 지원을 받을 수 있습니다.
