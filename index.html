전공안내

신입생이 전공을 선택하기 전에 ‘무엇을 배우고, 어떤 프로젝트를 하며, 졸업 후 어디로 갈 수 있는지’를 한 페이지에서 이해할 수 있도록 구성했습니다.

👁 보고

카메라·LiDAR·IMU 등으로 주변 환경을 측정하고, 컴퓨터비전과 딥러닝으로 객체·차선·공간을 이해합니다.

🧠 판단하고

현재 위치와 상태를 추정하고, 목표까지의 경로를 계획하며, AI를 이용해 상황에 맞는 행동을 결정합니다.

⚙️ 움직인다

계획된 행동을 조향·속도·모터 제어로 연결해 실제 차량과 로봇이 원하는 움직임을 수행하도록 만듭니다.

전공 선택 시 생각해볼 점
코딩만 하는 전공이라기보다 AI + 소프트웨어 + 센서 + 로봇 + 제어를 함께 다룹니다. 수학과 프로그래밍 기초를 바탕으로 실제 장비를 움직이고 실험하는 과정에 관심이 있다면 잘 맞습니다.

비교과 프로그램

로봇·자율주행 프로젝트, 학부연구생 활동, 공모전·대회 참가, 캡스톤디자인, 연구실 프로젝트 등 수업 밖에서도 실제 시스템을 다뤄볼 수 있습니다.

재학생의 실제 경험

시뮬레이션에서 끝나지 않고 F1TENTH 차량, LIMO 로봇, 대회 프로젝트, VLM 기반 자율주행처럼 센서와 AI를 실제 시스템에 적용하며 디버깅하고 성능을 개선합니다.

VLM Navigation

Vision-Language Model을 로봇·자율주행 내비게이션 문제에 적용해 이미지와 자연어 지시를 함께 이해하고 주행 행동을 결정하도록 학습한 프로젝트입니다.

  • Base model: Qwen/Qwen3-VL-2B-Instruct
  • 입력: Navigation instruction + 연속 RGB 이미지 2장
  • 이미지 크기: 256×256
  • Vision encoder(Qwen3 ViT)는 고정
  • Language model의 q_proj / v_proj에 LoRA 적용
  • 4가지 주행 action string 중 하나를 예측
  • LoRA rank 16 / alpha 32 / dropout 0.05
  • 10 epochs · AdamW · cosine warmup
VLMQwen3-VLLoRAVision-Language
VLM을 쉽게 이해하면
전통적인 자율주행은 센서 데이터에서 인식·위치추정·경로계획을 단계별로 연결합니다. VLM은 여기에 언어 이해를 더해 “앞의 장애물을 피해 오른쪽으로 이동해” 같은 자연어 지시와 이미지를 함께 보고 높은 수준의 행동을 결정하는 방향을 실험합니다.
