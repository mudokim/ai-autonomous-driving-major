이 전공에서는 무엇을 하나요?

핵심은 단순히 AI 모델을 만드는 것이 아니라, 센서로 세상을 인식하고 판단한 뒤 실제 로봇이나 차량이 움직이도록 만드는 것입니다.

1. 보고 👁

카메라와 LiDAR 등으로 주변 환경을 인식합니다. 컴퓨터비전과 딥러닝으로 객체, 차선, 공간을 이해합니다.

2. 판단하고 🧠

현재 위치를 추정하고, 어디로 갈지 경로를 계획하고, 상황에 맞는 의사결정을 수행합니다.

3. 움직인다 ⚙️

제어 알고리즘을 이용해 조향, 속도, 모터를 움직여 계획한 행동을 실제 시스템에서 실행합니다.

Vision-Language Navigation

VLM 기반 자율주행 · Navigation

이미지와 자연어 지시를 함께 이해하는 Vision-Language Model을 이용해, 주행 상황을 해석하고 행동을 선택하는 멀티모달 자율주행 프로젝트입니다.

  • Navigation instruction + 연속 RGB 이미지 2장 입력
  • Qwen3-VL 기반 멀티모달 이해
  • Vision encoder 고정 + LoRA fine-tuning
  • 4가지 주행 action 중 하나를 예측
  • 이미지 인식과 언어 기반 의사결정을 하나의 모델로 연결
VLMQwen3-VLLoRAMultimodal AINavigation
VLM 입력 / 결과 화면연속 RGB 이미지 2장, 자연어 지시문, 예측된 Driving Action을 한 화면에 보여주면 이해하기 쉽습니다.

Booth Mission
작은 로봇이 스스로 FINISH까지 갈 수 있을까?

부스에서는 라인트레이싱 또는 장애물 감지 미니 로봇을 이용해 간단한 자율주행 체험을 진행할 수 있습니다. 체험 후 실제 F1TENTH 영상으로 연결하면 '센서 → 판단 → 제어' 개념이 자연스럽게 이어집니다.

준비물예상 용도예산 예시
